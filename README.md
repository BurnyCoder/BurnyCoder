## Some of the projects I work/worked on
- [Reinforcement Learning Locomotion Steering Vectors](https://github.com/BurnyCoder/reinforcement-learning-locomotion-steering-vectors): Reverse engineering by mechanistic interpretability of reinforcement learning without human data from just experience of locomotion agent by finding and adding a steering vectors to policy's hidden activations to produce changes in behavior, such as sideways velocity. Collects unsteered rollouts, extracts contrasting activation means, selects intervention strengths on validation episodes, and checks them on fresh paired episodes. Uses Python + uv, PyTorch + Torchvision, Stable-Baselines3, Gymnasium + MuJoCo, Hugging Face Hub, NumPy, SciPy.
- [Deep work monitor: Jarvis Waifu Supervisor](https://github.com/BurnyCoder/jarvis-waifu-supervisor): AI-powered productivity monitor that watches your screen and webcam to keep you focused on your tasks. - [Training facts into LLMs](https://github.com/BurnyCoder/training-facts-into-llms): Training a fact into LLM using HuggingFace Transformers, PEFT, TLR using text-only BF16 LoRA with frozen vision, fine-tuning on fact, minimal-pair contrast, and knowledge-rehearsal examples, selecting checkpoints on a disjoint six-example validation set after an untouched-base baseline, and evaluating recall, near-name, knowledge retention.
- [Neurons of a Looped Language Model: neuron-level mechanistic interpretability and causal steering of Ouro-1.4B](https://github.com/BurnyCoder/looped-transformers-llms-neuron-mechanistic-interpretability): Studying individual neurons of a looped (recurrent-depth) transformer language model [ByteDance/Ouro-1.4B](https://huggingface.co/ByteDance/Ouro-1.4B) using GoodFire's neuron-reading approach in "[Neural Networks Are Already Clean](https://already-clean.goodfire.com/)": read raw neurons and their positive/negative poles directly from max-activating text, label them, steer them, and ablate them against random neurons from the same layers. Neurons found associated with phonetics and letters, non-duality, pedagogy, electron orbitals. Uses HuggingFace Transformers, datasets, llama.cpp.
- [Visualizing grokking modular addition in transformer](https://github.com/BurnyCoder/visualizing-grokking-modular-addition-in-transformer): Mechanistic interpretability of one-layer transformer that groks addition modulo 113 visualized in an explorable website, with a the reproducible pipeline behind it. The network was reverse-engineered by [Nanda, Chan, Lieberum, Smith & Steinhardt (2023), Progress measures for grokking via mechanistic interpretability](https://arxiv.org/abs/2301.05217).
- [Causal counterfactual analysis of convolutional neural networks with concept swaps interventions](https://github.com/BurnyCoder/causal-counterfactual-analysis-of-convolutional-neural-networks-with-concept-swaps-interventions): Mechanistic interpretability of InceptionV1 convolutional neural network. Do the famous curve-detector neurons of actually carry curve orientation to the rest of the network, or do they only correlate with it? Answered with causal tests with counterfactual interchange interventions, also called concept swaps or activation patching. 
- [Does a Coherent Extrapolated Volition system prompt make LLMs more aligned](https://github.com/BurnyCoder/coherent-extrapolated-volition-system-prompt-alignment): Putting Coherent Extrapolated Volition into an LLM system prompt. It then measures whether that prompt beats a classic "helpful, respectful and honest assistant" system prompt on alignment evals chosen to test what CEV is for. It reuses Inspect (UK AI Security Institute and Meridian Labs) and existing public benchmarks, and calls every model through OpenRouter.
- [Auto but actually fact checker evaluator](https://github.com/BurnyCoder/auto-but-actually-fact-checker-evaluator): Configurable rigorous LLM fact-checker with UI. You can run it anywhere from one non-agentic API call up to Claude Code / Codex agents with subagents. Uses Gradio, OpenAI Python SDK, Anthropic Python SDK, scikit-learn, statsmodels, matplotlib.
- [3D firstperson shooter reinforcement learning selfplay](https://github.com/BurnyCoder/3d-firstperson-shooter-reinforcement-learning-selfplay): Self-play RL in 3D first-person shooter from scratch through historical self-play with PPO using TorchRL and generalized advantage estimation (GAE), with the MAPPO shared-actor and centralized-critic setup for team stages. Combines Goodfire's [Structuring Sparsity: Block-Sparse Featurizers Capture Visual Concept Manifolds](https://arxiv.org/abs/2606.25234) with Apollo's end-to-end sparse autoencoders [Identifying Functionally Important Features with End-to-End Sparse Dictionary Learning](https://arxiv.org/abs/2405.12241).
